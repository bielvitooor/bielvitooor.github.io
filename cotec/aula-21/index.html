1. O QUE É SOFTWARE?

(Da Estrutura Física às Instruções Lógicas)

Uma Máquina Poderosa... Sem Programas

Imagine um computador recém-montado com processador de última geração, 16 GB de RAM, SSD rápido, monitor 4K, teclado e mouse.

Pergunta: Só com essas peças físicas, como o usuário consegue redigir um ofício, calcular uma folha de pagamento ou acessar um site?

O hardware é a estrutura física; o software fornece as instruções que transformam peças eletrônicas em ferramentas de trabalho.

Hardware vs. Software

Software é o conjunto de programas, instruções e dados que controlam os recursos do computador e executam tarefas para o usuário.

Hardware (Parte Física) Software (Parte Lógica)
Pode ser tocado fisicamente Formado por instruções, códigos e dados
Executa operações elétricas e mecânicas Define o que fazer e como operar
Exemplo: Teclado Exemplo: Editor de Texto
Exemplo: Monitor / Impressora Exemplo: Sistema Operacional / Driver

2. AS 3 CATEGORIAS

(Sistema, Aplicativo e Utilitário)

Classificação Segundo a Função

Existem milhares de programas, mas eles se dividem em três grandes grupos funcionais:

1. Sistema

Gerencia o hardware e cria a base para outros programas rodarem.

Ex: Windows, Linux, Android, Drivers.

2. Aplicativo

Permite ao usuário realizar tarefas específicas do dia a dia.

Ex: Word, Excel, Chrome, VLC, Paint.

3. Utilitário

Apoia a proteção, limpeza, organização e diagnóstico do sistema.

Ex: Antivírus, 7-Zip, Limpeza de Disco.

1. Software de Sistema (A Base de Tudo)

Sistemas Operacionais (SO)

Exemplos: Windows, Linux, macOS, Android, iOS.

  • Controla CPU, memória RAM e armazenamento.
  • Organiza arquivos, pastas e permissões.
  • Oferece a interface visual (Área de Trabalho, janelas) para o usuário.

Drivers de Dispositivo

São pequenos softwares que ensinam o sistema operacional a conversar com cada peça de hardware.

Ex: Driver de vídeo, áudio, rede Wi-Fi e impressora.

2. Software Aplicativo (Ferramentas do Usuário)

São os programas que abrimos para estudar, trabalhar, criar e comunicar:

Escritório

Textos: Word, Writer, Docs.
Planilhas: Excel, Calc, Sheets.

Web e Comunicação

Navegadores: Chrome, Edge, Firefox.
Reuniões: Teams, Zoom, WhatsApp.

Mídia e Imagem

Imagens: Paint, GIMP, Photoshop.
Vídeos/Áudio: VLC, Media Player.

3. Software Utilitário (Apoio e Manutenção)

Focados em manter o computador seguro, organizado e funcionando bem:

  • Antivírus: Protege contra malwares e ameaças digitais (ex: Microsoft Defender).
  • Compactadores: Reduzem tamanho e agrupam arquivos (ex: 7-Zip, WinRAR).
  • Limpeza de Armazenamento: Remove arquivos temporários desnecessários (ex: Limpeza de Disco).
  • Ferramentas de Backup e Diagnóstico: Criam cópias de segurança e monitoram o sistema.

3. EXPLORANDO O WINDOWS

(Reconhecendo Programas na Prática)

Mapeando o que Está Instalado

No ambiente Windows, podemos inspecionar os softwares instalados em três locais principais:

Menu Iniciar

Lista alfabética de todos os aplicativos e barra de pesquisa rápida.

Sistema > Sobre

Mostra a edição e versão exata do Sistema Operacional instalado.

Gerenciador de Tarefas

Atalho Ctrl + Shift + Esc: revela aplicativos abertos e processos em segundo plano.
