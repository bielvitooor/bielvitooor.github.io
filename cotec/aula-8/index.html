O Editor de Imagens (Paint)

A ferramenta mais clássica do Windows para criar e editar imagens simples é o Paint.

  • Permite fazer marcações rápidas numa imagem (ex: circular uma assinatura num documento escaneado).
  • Possui ferramentas básicas: Lápis, Pincel, Borracha, Balde de Tinta e Formas Geométricas.
  • Para abri-lo: Menu Iniciar > Digite "Paint" > Enter.

Prática 1: O Primeiro Esboço

Vamos usar o rato como o nosso pincel virtual.

Abra o Paint e crie um desenho livre, mas que obrigatoriamente contenha:

  1. Pelo menos duas formas geométricas (ex: círculo e retângulo).
  2. Pelo menos duas cores diferentes (use o Balde de Tinta).
  3. O seu Nome, escrito utilizando a ferramenta de Texto (a letra "A").

Salvando a sua Arte

Lembre-se da lição passada: "Se não está salvo, não existe".

  • Vá a Arquivo > Salvar Como.
  • Escolha a pasta "Aula 8".
  • Nomeie como: Meu_desenho.png.

Nota: O ".png" é a extensão que avisa o computador que aquilo não é um texto, mas sim uma Imagem de alta qualidade.

A Arte de Compactar (Arquivos ZIP)

Imagine que tem 50 fotos e precisa enviar todas para um cliente por e-mail. Anexar uma por uma demoraria muito tempo.

O Arquivo ZIP

Funciona como uma Mala de Viagem prensada a vácuo. Coloca os 50 arquivos lá dentro, o Windows aperta tudo num pacote só (reduzindo o tamanho) e o envia de uma vez.

Compactar vs. Extrair

O processo tem sempre duas vias:

Compactar

Ato de pegar os arquivos soltos e colocá-los dentro da mala de viagem com fecho (O arquivo ZIP).

Extrair (Descompactar)

Ato de receber a mala, abri-la e retirar os arquivos soltos de volta para a sua mesa, para poder utilizá-los normalmente.

Prática 2: Arrumando a Mala

Vamos empacotar o nosso desenho.

  • Passo 1: Vá à pasta Aula 8 e crie uma pasta chamada Materiais.
  • Passo 2: Coloque o seu desenho lá dentro.
  • Passo 3: Clique com o botão direito na pasta "Materiais".
  • Passo 4: Escolha "Enviar para > Pasta Compactada (zipada)" (ou "Compactar para arquivo ZIP").

Prática 3: Abrindo a Mala

Agora vamos retirar os arquivos de dentro do pacote ZIP.

  • Passo 1: Crie uma nova pasta chamada Extraídos.
  • Passo 2: Mova o seu arquivo "Materiais.zip" (a mala que acabou de criar) lá para dentro.
  • Passo 3: Clique na mala ZIP com o botão direito.
  • Passo 4: Escolha "Extrair Tudo..." e clique em Extrair. A pasta original irá aparecer solta novamente!

Ouvindo e Assistindo: Mídia

O computador também é uma máquina de entretenimento e comunicação.

  • Para abrir músicas (Áudio) e filmes (Vídeos), usamos os Reprodutores de Mídia.
  • As extensões mais famosas para áudio são: .mp3 e .wav.
  • As extensões mais famosas para vídeo são: .mp4 e .avi.

Prática 4: Controlando a Mídia

Utilizando os arquivos que forneci:

  1. Abra o arquivo de áudio. Localize o botão Play/Pause (► / ⏸).
  2. Experimente aumentar e diminuir o Volume do programa.
  3. Abra o arquivo de vídeo. Utilize a Barra de Progresso para avançar o vídeo para a metade.

O Desafio Integrado do Operador

Sem ajuda, faça a seguinte sequência lógica na sua pasta de trabalho:

1. Crie uma pasta chamada Entrega Final.

2. Copie o seu desenho (Meu_desenho.png) para lá.

3. Compacte a pasta Entrega Final num pacote ZIP.

4. Extraia o pacote ZIP para uma nova pasta chamada Conferência para garantir que o desenho está lá dentro.
